# Puffe TD

A 2D tower defense roguelike built in Godot 4.3, where you play as the dragons — defending ancient castles from invading humans and creatures.

## Concept

In most tower defense games, you defend against monsters. In Puffe TD, **you are the monsters**. Place dragon towers to protect the old castles from waves of encroaching humans and other enemies.

## Features

### Towers
- **Bolt** — fast, single-target lightning attacks
- **Nova** — area-of-effect burst damage
- **Beam** — sustained beam damage
- **Leopard Trap** — a trap-style tower that catches enemies off guard

Each tower can **level up** and choose an **elemental specialisation**, giving you meaningful upgrade decisions as the game progresses.

### Walls
Place cheaper wall structures to slow enemies down or maze their path — a key part of managing the battlefield dynamically.

### Roguelike Progression
- Enemies drop **experience** when defeated
- On **level up**, choose from a set of random improvements
- No two runs play the same

### Enemies & Levels
- Multiple enemy types across several different levels
- Enemies spawn from multiple spawn points in escalating waves

## Built With

- [Godot 4.3](https://godotengine.org/)
- GDScript
- [Beehave](https://github.com/bitbrain/beehave) — behaviour tree library for enemy AI

## How to Run

1. Clone the repository
2. Open Godot 4.3 or later
3. Import the project via `project.godot`
4. Press **Play**

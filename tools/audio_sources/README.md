# Audio sources

Downloaded sound packs, kept here to pick sounds from. Only this README is committed; the
packs are gitignored and `.gdignore` keeps Godot from importing them. Copy a picked sound
into `assets/audio/sfx/<pack>/` and list it in that folder's license file.

All CC0 (public domain), human-made, downloaded 2026-10-23:

| Folder | Pack | Source |
|---|---|---|
| `junkala_retro_512/` | Juhani Junkala (SubspaceAudio), The Essential Retro Video Game Sound Effects Collection [512 sounds], 2016 | https://opengameart.org/content/512-sound-effects-8-bit-style |
| `kenney_rpg-audio/` | Kenney, RPG Audio | https://kenney.nl/assets/rpg-audio |
| `kenney_impact-sounds/` | Kenney, Impact Sounds | https://kenney.nl/assets/impact-sounds |
| `kenney_interface-sounds/` | Kenney, Interface Sounds | https://kenney.nl/assets/interface-sounds |
| `kenney_music-jingles/` | Kenney, Music Jingles | https://kenney.nl/assets/music-jingles |

Not downloaded: Leohpaz, RPG Essentials SFX Free (https://leohpaz.itch.io/rpg-essentials-sfx-free).
It is free to use in games with no credit needed, but not CC0: the files may not be redistributed,
and this repo is public. If it is used, its sounds must stay out of git.
